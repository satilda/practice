## **Конспект по Git**

* Git придумал Линус Торвальдс, создатель Linux — потому что ему не понравились другие системы контроля версий 😎

* В среднем, один разработчик делает 20–30 коммитов в день.

* Git хранит изменения в виде дельт (разниц), а не целых файлов — поэтому он быстрый и экономит место.

* Можно использовать Git даже без GitHub — локально, как офлайн-хранилище кода.

### Основные команды

git init    создаёт новый репозиторий в текущей папке
git clone <url>    клонирует (копирует) репозиторий
git status    показывает состояние файлов (новые, изменённые, неотслеживаемые)
git add <file>    добавляет файл в “зону ожидания” для коммита
git commit -m "сообщение"    фиксирует изменения (делает снимок)
git log    показывает историю коммитов
git push    отправляет изменения на GitHub
git pull    получает и объединяет изменения с GitHub
git remote -v    показывает адреса подключённых репозиториев
